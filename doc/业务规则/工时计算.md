# 工时计算

## `calcNet(in, out)`
毛时长 − 与午休 `[12:00, 13:30]` 的重叠 − 与晚饭 `[19:30, 20:00]` 的重叠。
（实现：`src/lib/workHours.ts`）

## 9 小时标准
`DAILY_TARGET = 9`。当月目标 = `9 × 当月工作日数`。

## `floorTo30Min(h)`
补时长（rest day 计入的）按 0.5h **向下**取整：
- `2h02m → 2h`
- `3h39m → 3h30m`
- `2h29m → 2h`
- `5h37m → 5h30m`
workday 精确到分钟，**不**取整。

## `isEntryCounted(counts, isWorkday)`
- workday 默认 `true`、rest day 默认 `false`
- `counts` 显式覆盖（`true` / `false`）
- `true` → 计入；`false` → 不计入；`undefined` → 按默认

## 周末补时长计入工时
`counts === true` 的 rest day：
- 净工时 `floorTo30Min` 取整
- **直接加入 `done`**，**不**经 9h 扣减（盈亏对补时长是 +net，不是 net − 9）

## 盈余 / 缺口
```
balance = done − 9 × (计入的 workday 天数)
```
`done` = workday 精确 net 之和 + rest day 取整后 net 之和。
