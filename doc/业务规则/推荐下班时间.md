# 推荐下班时间（Dashboard 顶部卡）

## 目标日
- 今天（workday 且未打卡）→ 目标日 = 今天
- 已打卡 / 周末 / 假日 → 目标日 = 下一个 workday

## 算法
- 剩余工作日 = 目标日（含）到月末的 workday 数
- `targetNet = 9 − balance / remaining`，clamp `[6h, 12h]`
- 下班分钟 = `Math.round(8×60 + 90 + targetNet×60)`
- 显示 = `HH:MM`

## 关键点
- **核心公式** `targetNet = 9 − balance / remaining`（注意符号：亏 = balance 为负，减去负 = 加 = 晚下班，方向才对）
- 8:00 上班 + 1.5h 午休 = 17:30 基础下班；9h 净工时 = 18:30
- `Math.round` 防浮点尾巴（`targetNet * 60` 可能带 `.3333`，不 round 会显示 `18:20.1333...`）

## 跨月
- 目标日跨月 → 余额按 0 算（"下个月还没积累"），remaining = 目标日（含）到下月月末的 workday 数
