# 2026-07-12 运行时 bug 与工具坑

每条：**现象 / Root cause / 修复 / 怎么避免**。**写"为什么会发生"比"怎么修"更重要**——以后遇到类似情况能快速对号入座。

## 1. TrendChart 缺 `hMap` 解构 → ReferenceError
- **现象**：页面空白，控制台 `ReferenceError: hMap is not defined`
- **Root cause**：加了 `hMap?: HolidayMap` prop，但函数签名 `{ y, m, entries }` **没解构** `hMap`，`hMap` 既不是参数也不是局部变量
- **修复**：加进解构 `function TrendChart({ y, m, entries, hMap }: Props)`
- **怎么避免**：改 prop 签名时立刻 grep 校验。`vite build`（esbuild）不 type-check 不抓"未声明引用"

## 2. Dashboard 写 `viewY` 而 prop 是 `y` → ReferenceError
- **现象**：页面空白
- **Root cause**：`App.tsx` 的 state 叫 `viewY`/`viewM`，子组件 `Dashboard` 的 prop 叫 `y`/`m`。在 Dashboard 里写了 `viewY`（父 state 名）→ 未声明
- **修复**：全部 `viewY → y`、`viewM → m`
- **怎么避免**：**子组件永远用 prop 名，不要用父 state 名**。本项目连续踩两次

## 3. Dashboard 缺 `fmtDate` import → ReferenceError
- **现象**：`ReferenceError: fmtDate is not defined`
- **Root cause**：把 useMemo 抽到 `useMonthStats` 时把 Dashboard 的 `workHours` import 精简成 `{ DAILY_TARGET, fmtDuration }`，**漏了 `fmtDate`**。但 `const todayEntry = entries[fmtDate(ty, tm, td)]` 还在用 `fmtDate`。esbuild 把 bare `fmtDate` 当合法 global 放过
- **修复**：加回 `fmtDate` 到 import
- **怎么避免**：精简 import 时先 grep 用到的 symbol。tsc --noEmit 立刻报 `Cannot find name 'fmtDate'`

## 4. `shownNet` / `displayNet` 类型 `number | null` 不严
- **现象**：runtime 不报错（JSX guard `net != null` 兜底），但 tsc 报 `number | null not assignable to number`
- **Root cause**：三元 `isCounted && isRest ? floorTo30Min(net) : net` — false 分支返回 `net`（可能 null），类型被推为 `number | null`
- **修复**：用 `net!` 非空断言（外层 JSX 已 guard `net != null`，断言安全）
- **怎么避免**：tsc --noEmit 在 build 阶段抓

## 5. JSDOM 不能跑 `vite-plugin-singlefile` module script
- **现象**：JSDOM 加载 dist，`<script type="module">` **不执行**，root 永远空，**不报错** → 假阳性 "PASS"
- **Root cause**：JSDOM 不支持 ES module 加载（已知限制）；且 bare global（`document` 等）在 vm context 里不在 global 上（prototype chain 复制不全）
- **怎么避免**：跑真 headless（Playwright/Puppeteer）才算数。JSDOM + module script = 不可靠

## 6. `Edit` 工具 `old_string` 不精确匹配
- **现象**：`Edit` 报 "String to replace not found in file"
- **Root cause**：`old_string` 与文件实际内容不完全一致（缩进空格数、换行位置、import 行有无）
- **怎么避免**：**改任何文件前先 `Read` 拿当前精确文本**；或用 `grep -n` 定位后用**短而唯一**的锚点（不要整段照抄）
