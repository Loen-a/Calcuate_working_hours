# 2026-07-12 项目首日开发（从 0 到能跑 + 文档化）

## 做了什么
- 脚手架：React 19 + Vite + TS + Tailwind v4 + Recharts，`vite-plugin-singlefile` 单文件产物 `dist/index.html`
- 月历打卡（点击录入 / 编辑）+ 4 张统计卡（当月目标 / 已完成 / 盈余缺口 / 工作日）+ 累计盈余走势图
- 自定义 `TimePicker`（冷调 + mask 渐隐滚动条 + 自定义 checkbox 开关）
- 业务规则定下：9h 标准、12:00-13:30 午休扣减、19:30-20:00 晚饭扣减
- 周末/法定假日「计入工时」开关：默认关，开了直接加进余额（不经 9h 扣减），并按 30min 向下取整
- 推荐下班时间卡（`08:00 → HH:MM`，目标日 = 今天未打卡 / 下一个 workday）
- 主题切换（冷色 / 淡雅青绿）+ 手动导出导入 JSON（落 `data/` 文件夹）
- build 接 tsc --noEmit（`"build": "tsc --noEmit && vite build"`）
- 文档化：`README.md` + `doc/` 目录（项目日志 / 业务规则 / 踩坑记录 + 各子目录的 CLAUDE.md 指南）

## 决策
- **单页面 + 单文件 dist**：不依赖后端，浏览器双击即开，localStorage 存数据
- **主题切换模式**：`data-theme` 属性 + CSS 变量覆盖，工具类名（`text-navy` 等）不动，业务零改动
- **命名约定**：`App` 的 `viewY/viewM` state vs 子组件 `y/m` prop（连续踩两次坑后立的规矩）
- **补时长取整**：rest day 计入按 0.5h 向下取整（公司 30min 粒度）
