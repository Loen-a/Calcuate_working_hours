# 数据存储与备份

## localStorage
所有用户数据在浏览器 `localStorage`，**不在项目文件夹里**。

| key | 内容 |
|---|---|
| `workhours_v1` | 打卡 entries（`{ in, out, counts? }`） |
| `workhours_theme_v1` | 主题（`'cool'` / `'teal'`） |
| `holidaycn_v1_<year>` | 节假日缓存（按年） |

## 浏览器会清掉 localStorage 的场景
- 手动「清除浏览数据」/ 卸载浏览器 / 换浏览器换设备
- 隐私/无痕模式（关窗即清）
- iOS Safari 约 7 天未访问该 `file://` 站点后可能回收
- **`frontend/dist/index.html` 路径一变**（挪文件夹/改名/换盘）→ origin 变 → 旧数据读不到（**最隐蔽的坑**）

## 手动备份
- 顶栏 `导出` → 下载 `workhours-YYYY-MM-DD-HH-mm-ss.json`，存到项目下 `backend/data/` 文件夹
- 顶栏 `导入` → 选 JSON 覆盖当前 entries（有数据先 `confirm`）
- 想"默认到 backend/data/"：在 Chrome 设置 → 下载 → 位置改到 `backend/data/` 文件夹（一次性）
