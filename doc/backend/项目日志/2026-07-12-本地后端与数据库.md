# 2026-07-12 本地后端与数据库

## 目标与架构

将原本依赖浏览器存储的单页应用改为本机单用户架构：FastAPI 同时提供构建后的单文件前端和 `/api/*`，SQLite `backend/data/workhours.db` 作为工时记录、主题与节假日缓存的唯一持久化来源。前端继续负责净工时、月度统计、走势图和推荐下班时间等派生计算。

Python 依赖使用项目内 Poetry 环境 `backend/.venv`，不修改全局 Python 环境。前端、后端与各自文档继续按 `frontend/`、`backend/`、`doc/frontend/`、`doc/backend/` 分离。

## 主要改动

- 后端增加数据库初始化、repository、service 和 FastAPI API 路由。
- 前端改用 API 读取和保存 entries、主题、节假日与备份，不再把 `localStorage` 当作正式数据源。
- `GET /` 提供 `frontend/dist/index.html`；构建产物不存在时返回带构建命令的 `503`。
- 启动命令固定为 `poetry -C backend run uvicorn backend.main:app --host 127.0.0.1 --port 8000`。

## 旧数据迁移与备份

- version 1 JSON 只替换 entries，保留当前主题和节假日缓存。
- version 2 JSON 备份和恢复 entries、主题、节假日缓存三类数据。
- version 2 在单个事务中恢复；完整校验或写入失败时全部回滚。
- 导出文件名精确到秒，格式为 `workhours-YYYY-MM-DD-HH-mm-ss.json`。
